# 既読回避（Read Receipt Block）

既読回避は `ReadReceiptHook` が担当します。LINE の既読送信をインターセプトして、チャット単位で既読をブロックします。

## 機能概要

- グローバル設定で既読回避機能の有効/無効を切り替え
- チャット単位で既読回避の有効/無効を設定
- チャット画面ヘッダーにトグルボタンを表示
- チャットリストに既読回避中のチャットにバツマークを表示
- チャットリスト長押しダイアログにトグルボタンを追加
- 送信時既読機能（送信直後に短時間だけ既読送信を許可）
- OFF にしたチャットでは既読送信を優先し、既読回避ブロックを適用しない

## 対象

| 対象 | 処理 |
|---|---|
| `LegacyTalkServiceClientImpl#r1` | Thrift 送出をダミー操作に置換 |
| `org.apache.thrift.l#b` | 低層 Thrift プロトコル経路をブロック |
| `at2.e#d` | 既読マネージャの送信メソッドをブロック |
| `dc8.b#e` | バッジクリアをローカル読み時のみブロック |
| `he9.c0`, `he9.s`, `me1.g`, `fo5.k` | フォールバック用名前付きメソッドをブロック |

## OFF チャット優先の挙動

- チャット単位 OFF は `read_receipt_disabled_chat_ids` に保存される
- 既読ブロック判定は `ReadReceiptSettings.shouldBlockForChat(chatId)` を共通利用する
- 送信経路で chatId を取れる場合はその chatId を優先して判定する
- chatId が取れない経路のみ、現在表示中チャット ID をフォールバックとして使う
- チャット画面離脱時（`onPause`）に現在チャット ID をクリアし、別チャットへ判定が残留しないようにする

## 設定

設定キー:

```txt
read_receipt_block_enabled          # グローバル設定
read_receipt_send_on_send           # 送信時既読
read_receipt_header_button_enabled  # ヘッダーボタン表示
read_receipt_disabled_chat_ids      # 既読回避を無効化するチャットIDリスト
```

デフォルトは無効です。設定 UI の `GENERAL > 既読回避` から切り替えます。

## UI

### チャット画面ヘッダー

チャット画面のヘッダーに目アイコン（既読回避無効時）またはバツアイコン（既読回避有効時）を表示します。タップするとトグルします。

### チャットリスト

既読回避が有効なチャットにバツマークを表示します。画面切り替え時に再描画されます。

### チャットリスト長押しダイアログ

チャットを長押しした際のダイアログに「既読回避: ON/OFF」ボタンを追加します。

## ログ方針

既読送信は高頻度で呼ばれるため、通常のブロック成功ログは出しません。フック登録失敗やエラーなど、調査に必要な失敗のみ記録します。

## 保存場所

設定は内部ストレージ（`context.getFilesDir()`）に JSON ファイルとして保存されます。SD カードは使用しません。
