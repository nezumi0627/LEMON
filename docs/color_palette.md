# Color Palette

LEMON のブランドカラーと UI で使う基本色です。

| 名前 | HEX | 用途 |
|---|---|---|
| Lemon Yellow | `#FFF352` | ブランドアクセント |
| White | `#FFFFFF` | カード/ヘッダー背景 |
| Screen Gray | `#F4F4F4` | 設定画面背景 |
| Text Primary | `#333333` | 主テキスト |
| Text Secondary | `#888888` | 補助テキスト |
| Section Blue | `#608bc5` | セクション見出し |
| Divider | `#EFEFEF` | 区切り線 |

新しい色を追加する場合は、既存の LINE 風 UI から浮かないことを優先します。
